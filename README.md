# 📐 Tableau Dashboard Resizer

A lightweight Streamlit app to resize dashboards in a Tableau workbook (`.twb` / `.twbx`) and automatically recompute the position of every object inside each dashboard.

---

## Features

- Upload a `.twb` or `.twbx` file
- Apply a common size to all dashboards in one click
- Resize each dashboard individually via an editable table
- Optionally shift objects to the right and/or downward when expanding
- Download the modified workbook in its original format (`.twb` or `.twbx`)
- French / English UI
